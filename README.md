# 🧠 Quiz Game

A responsive and interactive quiz game built with **HTML**, **CSS**, and **JavaScript**. Test your general knowledge by answering multiple-choice questions, track your score in real time, and view your final results with personalized feedback.

---

## 📖 Project Overview

This project demonstrates the fundamentals of front-end web development by building a complete quiz application from scratch using vanilla JavaScript.

The quiz dynamically displays questions, validates user answers, updates the score, tracks progress, and presents a results screen once all questions have been answered.

---

## ✨ Features

* 🎮 Interactive multiple-choice quiz
* 📊 Live score tracking
* 📈 Progress bar and question counter
* ✅ Visual feedback for correct and incorrect answers
* 🏆 Personalized result messages based on performance
* 🔄 Restart quiz functionality
* 📱 Responsive design for mobile and desktop devices

---
